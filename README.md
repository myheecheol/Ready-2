# AI 무역 분석가

비상 사회 6-2 「③ 세계의 무역」 12~16차시 · 데이터 분석형 AI 융합수업용 웹앱입니다.
`index.html` 파일 하나로 동작합니다(서버·로그인·데이터베이스 없음).

## 배포
- Netlify에 `index.html`을 끌어다 놓거나, 구글 사이트에 삽입한 뒤 링크/QR로 나눠 주세요.

## 사용
- **교사 모드**: 상단 열쇠 버튼 → 기본 숫자 `1234` (설정에서 바꿀 수 있어요). 보안 장치가 아니라 학생 화면에서 정답을 숨기는 용도입니다.
- **설정**(교사 모드): 모둠 수, 외부 링크(구글 설문·시트, 엔트리, KOTRA, 샘보드, Gem), 학급 데이터 백업·복원·초기화.
- **교사 도구 서랍**(오른쪽 아래): 타이머, 모둠 뽑기, 나라 제비뽑기, 링크 QR.
- **발표 모드**: 글자 1.4배, 상단 메뉴 숨김(전자칠판용).

## 15차시 무역 놀이
무역 놀이는 구글 Apps Script 앱으로 진행합니다(설정의 ‘15차시 무역 놀이 앱 링크’에 기본으로 들어 있음).
교사용·나라별 비밀번호는 교사 모드에서만 화면에 보입니다. 나라 이름과 비밀번호는 `CONTENT.game`에서 고치세요
(지금은 ‘한국’ 다음 나라를 ‘2번 나라’~‘6번 나라’로 적어 두었어요).

## 수업 내용 고치기
`index.html` 맨 위 `const CONTENT = {...}` 안의 글자만 고치면 화면에 반영됩니다.
